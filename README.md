# jellyfin-plugin-common

Shared source for the [Jellyfin](https://jellyfin.org) plugins in this family
([Ingest](https://github.com/chrisgrulau/jellyfin-ingest), [Subtitles](https://github.com/chrisgrulau/jellyfin-subtitles),
[AI](https://github.com/chrisgrulau/jellyfin-ai)): resilient calls to external services, retry and back-off, budgets,
rate limits and spend tracking.

It is not a plugin. See the [README](https://github.com/chrisgrulau/jellyfin-plugin-common#readme) once the repository is set up.
